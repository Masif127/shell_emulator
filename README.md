# Эмулятор языка оболочки ОС (Вариант №19)

## Общее описание проекта
Данный проект представляет собой эмулятор командной строки UNIX-подобной операционной системы, реализованный в форме графического интерфейса пользователя (GUI)[cite: 63]. Приложение функционирует в интерактивном режиме (REPL), поддерживает ввод параметров конфигурации командной строки, последовательное пакетное исполнение команд из стартового скрипта, а также оперирует изолированной виртуальной файловой системой (VFS), развернутой непосредственно в оперативной памяти компьютера без модификации исходных данных на диске[cite: 63, 64].

**Спецификация варианта №19:**
- **Интерфейс:** Графический интерфейс (GUI) с обязательным отображением имени VFS в заголовке окна[cite: 63].
- **Особенности парсера:** Простой парсер, разделяющий входную строку на имя команды и аргументы по пробелам[cite: 63].
- **Источник VFS:** CSV-файл (двоичные данные кодируются в base64; поддержана структура представления вложенных элементов)[cite: 64].
- **Основные команды:** `ls`, `cd`, `tree`, `head`, `exit`[cite: 63, 64].
- **Дополнительные команды (in-memory):** `mkdir`[cite: 65].

## Описание всех функций и настроек

### 1. Графический интерфейс и REPL-цикл (Этап 1)
- **Интерактивный диалог:** Непрерывный цикл обработки команд в графическом окне (GUI)[cite: 63]. Заголовок окна динамически содержит имя смонтированной виртуальной файловой системы[cite: 63].
- **Парсинг командной строки:** Простой парсер производит токенизацию введенной пользователем строки, разделяя имя исполняемой команды и переданные аргументы по пробельным символам[cite: 63].
- **Обработка и информирование об ошибках:** Реализована валидация пользовательского ввода с выводом сообщений о неизвестных командах и недопустимом количестве или составе аргументов без сбоя работы приложения[cite: 63].

### 2. Модуль конфигурации (Этап 2)
Запуск приложения настраивается через параметры командной строки[cite: 63]:
- `--vfs` — путь к физическому расположению CSV-файла виртуальной файловой системы[cite: 63, 64].
- `--script` — путь к стартовому скрипту для автоматического выполнения команд эмулятора[cite: 63].
- **Отладочный вывод параметров:** При старте эмулятора в терминал/область вывода выводится отладочная информация обо всех переданных аргументах конфигурации[cite: 63].
- **Стартовый скрипт:** Последовательно выполняет команды эмулятора, пропуская ошибочные строки[cite: 63, 64]. Имитирует интерактивный диалог: на экране синхронно отображается как ввод команды, так и результат её работы[cite: 64]. При возникновении ошибок исполнения выводится отдельное сообщение[cite: 64].

### 3. Виртуальная файловая система (VFS) (Этап 3)
- **Изоляция в памяти:** Все операции с каталогами и файлами осуществляются исключительно в оперативной памяти (In-Memory VFS)[cite: 64]. Запрещается распаковывать или физически изменять исходные файлы VFS[cite: 64].
- **Формат хранения:** Источником данных служит CSV-файл, содержащий древовидную структуру директорий[cite: 64]. Двоичное содержимое файлов сериализуется в формат base64[cite: 64].
- **Безопасность:** Создание папок и модификации состояния VFS сохраняются только во внутренних структурах в памяти до момента завершения процесса[cite: 64, 65].

### 4. Поддерживаемые команды (Этапы 1, 4, 5)
- `exit` — завершение работы эмулятора и корректное закрытие графического окна программы[cite: 63].
- `ls [путь]` — просмотр содержимого текущего или указанного каталога (на Этапе 1 — заглушка с выводом имени и аргументов; на Этапе 4 — чтение VFS)[cite: 63, 64].
- `cd [путь]` — смена текущей рабочей директории в VFS с валидацией существования пути (на Этапе 1 — заглушка с проверкой количества аргументов)[cite: 63, 64].
- `tree [путь]` — рекурсивный вывод дерева файлов и папок виртуальной файловой системы в текстово-графическом формате[cite: 64].
- `head [-n N] <файл>` — вывод первых строк содержимого указанного текстового файла из VFS[cite: 64].
- `mkdir <путь>` — создание нового каталога в виртуальной файловой системе в памяти[cite: 65].

## Инструкции по сборке и запуску

### Системные требования
- **Язык реализации:** Python версии 3.10 или выше.
- **Зависимости:** Проект использует стандартные библиотеки Python (`tkinter`, `csv`, `base64`, `unittest`), сторонние зависимости (pip) не требуются.

### Запуск эмулятора в интерактивном режиме (GUI)
Для запуска графического интерфейса с указанием пути к файлу виртуальной файловой системы введите команду в терминале:
```bash
python -m src.gui --vfs ./vfs.csv
